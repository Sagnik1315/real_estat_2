# Varenya Estates – Premium Real Estate Website

Varenya Estates is a modern, responsive real estate website designed to showcase premium residential and commercial properties across India. It provides an elegant browsing experience where users can explore property listings, filter homes based on their preferences, view detailed property information, and submit enquiries.

## ✨ Features

- **Modern Landing Page:** Premium design with an attractive hero section and smooth animations.
- **Property Listings:** Browse featured apartments, villas, residential plots, and commercial properties.
- **Advanced Property Filtering:** Filter properties by:
  - Location (Kolkata, Mumbai, Bengaluru, Gurugram)
  - Property Type
  - BHK Configuration
  - Budget Range
- **Property Details:** View property information, amenities, floor plans, pricing, and nearby connectivity.
- **Featured Project:** Dedicated showcase section highlighting signature real estate projects.
- **Enquiry Form:** Submit property enquiries with contact information and preferences.
- **WhatsApp Integration:** Direct communication through WhatsApp.
- **Contact Options:** Call and email links for customer enquiries.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Smooth Animations:** Interactive transitions and scroll-based reveal effects.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Sagnik1315/real_estat_2.git
```

### 2. Navigate to the project directory

```bash
cd real_estat_2
```

### 3. Install dependencies

```bash
pnpm install
```

Alternatively, using npm:

```bash
npm install
```

### 4. Start the development server

```bash
pnpm dev
```

Or:

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```

## 🏡 How It Works

1. Users land on the homepage and explore the featured real estate offerings.
2. They navigate to the property explorer section.
3. They apply filters according to their preferred location, property type, BHK configuration, and budget.
4. They browse matching properties and open individual property details.
5. Interested users can submit an enquiry or contact the property advisor through WhatsApp or phone.

## 🎯 Project Objective

The objective of this project is to build a professional real estate platform with an intuitive user interface, interactive property discovery features, and convenient enquiry options.

It demonstrates practical implementation of modern frontend development concepts, reusable React components, state management, responsive web design, and interactive user experiences.
